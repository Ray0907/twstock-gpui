# twstock-gpui

繁體中文 · [English](README.md)

一個**實驗性質**的 macOS 台股看盤桌面程式，自用為主。以 Rust 與 [gpui-kit](https://github.com/longbridge/gpui-kit) 原生繪製，不是包瀏覽器的網頁應用。

> **實驗專案說明**：這個 repo 是用 GPUI 打造原生看盤介面、實驗嚴格視覺與領域分離架構的個人專案。資料串接自非官方公開網頁端點，功能與涵蓋範圍仍有諸多限制，僅供技術實驗與個人看盤，並非正式交易軟體。

![深色主題](tests/snapshots/dark.png)

*截圖為固定種子的虛構範例資料（代號 `99` 開頭），並非真實行情。沒有設定檔時預設開啟此範例模式，clone 下來就能直接試用。*

## 畫面與操作

視窗分為三個可自由拖曳縮放的面板：**自選清單**（含迷你走勢線）、**K 線走勢圖**、**行情明細**（五檔、買賣比例、成交量與價格位置）。

- **看盤與走勢圖**
  - 自繪 K 線（收高實心、收低空心，不只靠顏色區分漲跌方向）、MA5 / MA10 / MA20、成交量副圖、最高最低價標註、金色十字游標與現價線。
  - 支援**日／週／月線**切換。週線與月線直接由已載入的日線聚合，不額外發送請求。（因為沒有免費分鐘線來源，介面不放停用的分鐘選項。）
  - 垂直滾動或觸控板捏合以游標為中心縮放，水平滾動或滑鼠左鍵拖曳平移；雙擊、切換商品或切換週期即可恢復全覽。
  - 遵循台股**紅漲綠跌**慣例、平盤為灰；價格與數量維持中性色，只有漲跌帶顏色。內建深色與淺色主題。

- **快捷鍵與搜尋**
  - `⌘K`：開啟商品搜尋（支援上市／上櫃的股票與 ETF），可依代號前綴或名稱子字串（不分英文大小寫）過濾；`↑`/`↓` 選取、`Enter` 加入自選、`Esc` 關閉。
  - `Delete` / `Backspace`：移除自選清單中選取的商品（也可點選自選標題旁的「…」選單移除）。
  - `⌘⇧R`：重設回預設面板版面（搜尋視窗開啟時不觸發）。

## 開始使用

### 環境需求

- **macOS（需支援 Metal）**：目前僅在 Apple Silicon 上驗證過。
- **完整版 Xcode**（不能只有 Command Line Tools），並安裝 Metal toolchain：
  ```sh
  sudo xcode-select -s /Applications/Xcode.app/Contents/Developer
  sudo xcodebuild -license accept
  xcodebuild -runFirstLaunch
  xcodebuild -downloadComponent MetalToolchain
  ```
- **[rustup](https://rustup.rs)**：`rust-toolchain.toml` 固定使用 `1.97.1`，首次建置時會自動安裝。
- 系統內建的 `curl`（用於發送行情請求）。

### 執行與打包

請在有螢幕的桌面 session 執行（無法從純 SSH 開視窗），首次建置約需數分鐘：

```sh
git clone <這個 repo>
cd twstock-gpui
cargo run --release
```

`cargo run` 啟動時會直接讀取 `assets/icon/icon-1024.png` 設定 macOS Dock 圖示。如果你想打包成獨立的 `.app` 應用程式：

```sh
./scripts/bundle-app.sh   # 產生 target/bundle/twstock-gpui.app
```

- 產出的 `.app` 未簽署，首次開啟可能需要在 Finder 按右鍵選「打開」。
- 圖示原圖 `assets/icon/icon-1024.png` 由 Gemini 圖像生成後去背；若要重新產生 `.icns`，可執行 `./scripts/make-icon.sh`（僅使用 macOS 內建的 `sips` 與 `iconutil`）。

### 自選清單設定

直接按 `⌘K` 搜尋並加入第一檔商品時，若原本處於範例模式，程式會明確提示建立 `~/.config/twstock-gpui/watchlist.toml` 並切換至真實 MIS 報價（不會把範例商品寫入你的設定檔）。你也可以手動建立：

```toml
[[watchlist]]
market = "tse"    # tse 上市、otc 上櫃
code = "889901"   # 範例代號，請換成自己要看的

[[watchlist]]
market = "tse"
code = "889902"
```

- **保留註解與排版**：在介面內新增或移除商品時，底層透過 `toml_edit` 原子寫回，會完整保留你原有的註解、格式、inline array 以及 `[[watchlist]]`、`[[symbol]]` 等既有別名。變更在下一輪輪詢（維持至少 5 秒間隔）即生效，不必重啟。
- **不偷偷退回範例**：設定檔不存在時使用範例資料；但若設定檔格式錯誤會直接顯示錯誤原因，不會悄悄退回範例模式。把清單刪到全空也會保存為空清單，重啟後維持空白。

## 資料來源與誠實狀態

這個專案的一個基本原則是：**拿不到或沒把握的資料就留白或明示原因，不捏造假數字填版面。**

- **連線狀態常駐**：狀態列隨時顯示連線中、正常、過期、失敗或休市，斷線絕不會被畫成平盤。
- **無成交價處理**：尚未有成交價時不畫現價線，並明示為「參考價」；也不會拿中間參考價去硬造當日日線。
- **明確的面板狀態**：載入中顯示置中 Spinner 與說明、失敗附上原因、無資料或視窗過小無法繪圖時皆在內容區置中提示。近期區間尚未載入完成前，不會閃現誤導人的「0 根日線」。

| 用途 | 來源 | 行為與限制 |
|---|---|---|
| **即時報價與五檔** | 證交所 MIS (`mis.twse.com.tw`) | 非官方端點，無保證。約 5 秒更新一次，程式輪詢不少於 5 秒。不提供逐筆成交（不支援時逐筆區塊整塊收起不佔空間）；盤中成交價欄位常為 `-`。 |
| **歷史日線** | 證交所 `STOCK_DAY` | 一次抓一個月，往前補到 100 根（最多回溯 12 個月）。**目前僅支援上市（TSE）**，上櫃歷史尚未串接。 |
| **商品清單** | 證交所 ISIN 公告清單（上市 `strMode=2`、上櫃 `strMode=4`） | 只收錄官方「股票」與「ETF」分類；嚴格依官方分類決定 ETF 升降單位（價階），不靠代號前綴猜測。 |

**快取與重試機制**：
- **歷史日線**快取於 `~/.cache/twstock-gpui/history/`（每檔一個檔案）。已結束的過去月份只有在「月底過後才抓到」才視為最終版不再重抓（月中抓到的舊快照會重抓）；當月快取則會重用到下一個平日收盤後（台北時間 14:00）才重抓。錯誤回應不寫入快取，快取損毀時自動退回網路抓取。目前選取的商品優先載入，其餘在背景排隊（請求間隔至少 2 秒；失敗時以 60 秒至最長 10 分鐘退避重試，點選該商品則立即重試）。
- **商品清單**快取於 `~/.cache/twstock-gpui/directory.json`（含抓取時間），24 小時到期後重抓，再次開啟搜尋時也會檢查是否到期；更新失敗時直接顯示原因，不使用假清單或過期快取。

> **免責聲明**：僅供個人看盤使用，非投資建議，亦不保證資料正確或即時。請勿自行調高輪詢頻率。

## 圖表與數據口徑細節

![十字游標](tests/snapshots/crosshair.png)

### 成交量顯示與尖峰截斷
- **張數與座標標籤**：實際成交張數四捨五入至整張並加千分位，量軸刻度保留 `k` / `M` 縮寫。游標指向某根 K 棒時，量副圖右軸標出該柱實際量；無游標時則淡色顯示最新量。日期、價格與量標籤皆會自動避讓軸刻度。
- **極端大量截斷**：為避免單一極端爆量把整張量副圖壓扁，當可視範圍最大量嚴格超過穩健上限 `nice(P95 × 1.2)` 的 **2.5 倍**時才啟用截斷（P95 採 nearest-rank `ceil(0.95 × 根數)` 且包含零量；少於 20 根時不截斷）。截斷柱會畫出斷口與真實量標籤，標題註明「截斷於 N」，十字游標仍讀取原始真實量。日／週／月線共用同一規則。
- **週／月線聚合**：週線依交易日所在 ISO 週分組（跨年亦依 ISO 週年），月線依年月分組；開盤取首日、收盤取末日、高低取極值、量加總，並將已知的今日即時日線納入當期。MA5 / 10 / 20 依目前週期重算，根數不足時顯示 `—`。

![週線](tests/snapshots/weekly.png)

![月線](tests/snapshots/monthly.png)

### 五檔下方的「位置」區塊
- **今日價格區間條**：以當日已知的低、高、昨收、開盤與成交價決定範圍，兩端各留 8% 空間（至少一個升降單位，讓平坦區間仍可讀）；昨收若跳空在當日高低之外仍會納入，參考價則不納入。各標籤會量測實際字寬後自動排開，並以引線連回原價位；跌停／漲停價另外標在軸下方左右兩端，不再壓縮當日波動比例。
- **近期區間百分位**：只取已載入日線的低／高並標出實際根數，不因切換週／月線而改變。現價百分位夾在 `0–100%`（高低同價且現價相等時取 `50%`，無成交價時顯示 `—`）。
- **量比（今日累計量／5 日均量）**：分母取報價日期前最近 5 根「完整日線」，不把當日未收盤的日線算進平均（少於 5 根、均量為零或缺少今日量時顯示 `—`；今日零量可顯示 `0.00×`）。盤中與未知時段標示「盤中累計」、盤後與休市標示「全日累計」——不做盤中經過時間的換算推估，也不自行給出放量／縮量結論。

## 專案結構與驗證

```text
src/
  design/    視覺的唯一來源：色階、字級角色、方向（漲跌）、間距、圓角、共用元件、圖表
  market/    行情領域型別、MarketStore、MIS 與歷史 provider、設定讀寫（不依賴 gpui）
  panels/    自選、走勢、行情、狀態列面板（只呼叫 design，不自行決定視覺數值）
tests/
  design_rules.rs          靜態掃描：design 以外若出現寫死的顏色、字級、字重、間距或圓角即失敗
  provider_conformance.rs  所有行情 provider 共用的行為測試
  rendering.rs             GPU 離屏渲染與視覺快照測試
  live_shot.rs             真實網路來源煙霧測試
```

- **視覺集中管理**：由 `design_rules` 測試強制約束，確保 `src/design/` 以外不散落任何視覺常數。
- **行情介面解耦**：UI 只依賴領域型別與 `MarketStore`（價格採單位 `0.0001` 的定點數，升降單位屬於商品本身）。未來若要串接券商 API 或 WebSocket，只需實作一個 provider 並通過 `provider_conformance`，UI 層不必修改。

### 執行測試

```sh
cargo clippy --all-targets -- -D warnings
cargo test
cargo test --test rendering
```

- **GPU 離屏渲染與 Golden 快照（`rendering`）**：在不開視窗的情況下用 GPU 離屏渲染並輸出 `/tmp/twstock-gpui-*.png`，可在 SSH 下執行（固定使用範例資料，不讀個人設定也不連網）。除了驗證版面邊界、拖曳縮放與搜尋互動外，也會將 10 個靜態場景與 `tests/snapshots/` 的基準 PNG 比對（以 2×2 box filter 縮小一半，單色頻差 ≤2 忽略，超過 0.05% 像素差異即失敗）。
  - 更新基準圖：`UPDATE_SNAPSHOTS=1 cargo test --test rendering`，執行後請人工檢視 `/tmp/twstock-gpui-snapshot/` 下的 `.actual.png` 與 `.diff.png`。
- **真實來源煙霧測試（預設不執行）**：
  ```sh
  # 讀取你的 watchlist.toml 實抓並輸出 /tmp/twstock-gpui-live-{dark,light}.png
  TWSTOCK_GPUI_LIVE=1 cargo test --test live_shot

  # 單獨驗證上市／上櫃商品清單端點的實抓筆數與耗時
  TWSTOCK_GPUI_LIVE=1 cargo test --test directory directory_live_opt_in -- --nocapture
  ```

## 已知限制

- **休市判斷**：目前依台北時間、週末與來源報價日期推斷，尚未串接正式交易日曆。
- **上櫃歷史與回溯長度**：上櫃（OTC）歷史日線尚未串接。上市日線目前最多回溯 12 個月（載入 100 根），聚合後週線約 20 餘根、月線約 5～6 根，因此月線的 MA10 / MA20 通常因根數不足而顯示 `—`。
- **商品搜尋範圍**：只涵蓋官方「股票」與「ETF」分類；權證、特別股、創新板、ETN、TDR、受益證券尚未納入，以避免猜測升降單位。
- **平台驗證**：僅在 macOS（Apple Silicon）上驗證過，尚無長時間連續執行的壓力測試。
